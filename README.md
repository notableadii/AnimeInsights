
# 📊 Cross-Media Reading & Watching Stats Platform Plan

## **Vision**

Create a unified platform where users can track **manga, manhwa, manhua, and anime**, visualize their consumption, and share insights. Extend the platform to Discord to allow users to showcase stats and engage socially.

---

## **1. Website Overview**

### **Core Purpose**

* Central hub for users to track all their reading and watching activities.
* Merge data from **multiple sources** (AniList, MyAnimeList, MangaDex, JSON imports).
* Provide actionable insights, visualizations, and shareable statistics.

### **User Journey**

1. **Sign Up / Login**: Users create an account to store their data.
2. **Connect Accounts / Import Data**:

   * Connect AniList / MyAnimeList via account authorization.
   * Import JSON files for offline tracking or additional sources.
3. **Track Activity**:

   * Automatic import updates reading/watching progress.
   * Manual updates allowed for unsupported content.
4. **View Dashboard**:

   * **Personal Stats**: Total titles, chapters/episodes completed, average consumption, top genres, streaks, binge habits.
   * **Cross-Media Insights**: Compare reading vs watching habits.
   * **Visual Insights**: Graphs, charts, infographics (“Wrapped” style).
5. **Share & Export**:

   * Share infographics on social media.
   * Download personalized cards or yearly summaries.
6. **Notifications** (optional):

   * Alerts when new chapters/episodes are released.
   * Streak reminders or weekly/monthly summaries.

### **Key Features**

* Reading & Watching Stats
* Cross-Media Insights
* Personalized Dashboard
* Visual Infographics
* Shareable Social Cards
* Notifications & Alerts
* Manual & Automated Progress Tracking

---

## **2. Discord Bot Overview**

### **Core Purpose**

* Extend platform functionality into **Discord servers**.
* Allow users to **showcase their stats**, compare with friends, and engage socially.

### **User Journey**

1. **Connect Discord Account**:

   * User links their platform account with Discord.
2. **Commands to Access Stats**:

   * **!stats** → View overall stats (titles completed, chapters/episodes, top genres).
   * **!wrapped [year]** → Generate a personalized infographic for social sharing.
   * **!top [category]** → See leaderboards for reading/watching achievements.
   * **!track [title] [progress]** → Update progress directly from Discord.
   * **!compare @friend** → Compare stats with friends.
3. **Notifications**:

   * Receive updates when new chapters/episodes are released.
   * Optional DM notifications for streaks or milestones.
4. **Social Engagement**:

   * Post “Wrapped” infographics in channels.
   * Share achievements and stats with communities.
   * Friendly competition via leaderboards.

### **Key Features**

* Display Personal Stats in Discord
* Generate Shareable Infographics
* Track Progress via Commands
* Compare Stats with Friends
* Receive Notifications & Updates
* Leaderboards & Community Engagement
